# spiel/ton/name/

Gehört **DEM NAMEN**. Hier liegt **keine** Datei, und das ist Absicht:
`kern/ton.js` lädt seine Proben ausschließlich aus `ton/klang/` (Zuständigkeit §11,
`kern/ton.js` gehört für Welle 2 DEM KLANG). Ein Stück, das eigene Dateien in seinen
eigenen Ordner legt, bekäme sie nicht zu hören.

DER NAME ruft deshalb nur — die Rufnamen stehen fest und ändern sich nicht mehr:

| Rufname | Wann | Was er sein sollte |
|---|---|---|
| `name:aushaengen` | Bierzeiger raus, Zeichen wieder zeigen | Holz auf Holz, ein Riegel, ein Kranz, der schwankt |
| `name:einziehen` | Zeichen verdecken, Auflage einstellen | dasselbe rückwärts, leiser, ohne Nachhall |
| `name:anschlagen` | Wirtshausschild/Umtrunk bei einer Adresse | Hammer auf Nagel, dreimal, dann Kette |
| `name:druck` | Etiketten, Plakate, Säule, Emailschild, Kronkorken | Steindruckpresse (III) · Blechpresse (IV) |
| `name:spot` | Fernsehspot | Bandmaschine anlaufend, ein kurzer Sendeton |
| `name:siegel` | Zunftzeichen, Warenzeichen, Zunftspruch, Unterlassung | Siegel in Wachs (I/II) · Stempel auf Akte (III/IV) |
| `name:urteil-gut` | ein gutes Urteil ins Register | ein zustimmendes Gemurmel, kurz |
| `name:urteil-schlecht` | ein schlechtes Urteil ins Register | dasselbe Gemurmel, tiefer, mit einem Absatz darin |
| `name:nachahmung` | der Adler führt dasselbe Zeichen | ein zweiter, falscher Schlag desselben Hammers |
| `name:verlust` | eine Adresse geht wegen des fremden Namens weg | Tür, die zugeht |
| `name:zulauf` | ein Wirt fragt von selbst an | Tür, die aufgeht, Schritte herein |
| `name:mundpropaganda` | herumgehen und den Namen sagen | Schritte auf Pflaster, Stimmen im Hintergrund |
| `name:rueckruf` | Rückruf 1970 | Telefon, aufgelegt; Kästen, die zurückgeladen werden |
| `name:verkauf` | der Name ist verkauft | ein einzelner Stempel, dann Stille |
| `name:aufgeld` | DAS AUFGELD ist auf eine Fuhre gebucht worden | Münzen, die auf ein Brett gezählt werden — kurz, drei bis vier Stück |

Solange keiner davon im Katalog steht, greift der Notfall von `kern/ton.js` und spielt
ein Blatt Papier. Der Ruf geht also nicht ins Leere — er ist nur noch nicht
unterschieden. **Bitte an DEN KLANG:** diese fünfzehn Namen in `KATALOG` aufnehmen,
oder wenigstens eine Vorsilbe `name:` in `NOTFALL`. Vorschlag für die Vorsilbe:
`altNeu('siegel', 'kasse')` — Wachs und Kasse sind beide „hier wird etwas
festgemacht" und liegen bereits im Ordner.

Zwei Rufe sind je Epoche verschieden gedacht und wären der Latte-3-Gewinn dieses
Stücks: `name:druck` (Steindruck gegen Blechpresse) und `name:siegel`
(Wachs gegen Aktenstempel). Beides ist derselbe Vorgang — *etwas verbindlich machen* —
und klingt 1600 anders als 1970.
